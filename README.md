# 岩石きょうだいクイズ

中学受験理科「火成岩」（深成岩・火山岩の6種類）を、物語とクイズ形式で楽しく覚えるための静的Webアプリです。

## 特徴

- 火成岩6兄弟（カコウ岩・センリョク岩・ハンレイ岩・リュウモン岩・アンザン岩・ゲンブ岩）を擬人化した物語（全5話＋岩石図鑑）
- 「でき方×色」の分類クイズ、組織・鉱物のヒントから当てる岩石名当てテスト
- 両方をランダムミックスした「まとめテスト」
- 達成度の記録と、間違えた項目だけを出題する「苦手だけ出題」機能（ブラウザのlocalStorageに保存）
- 正解・不正解時の効果音と、毎回変わる応援メッセージ

## 使い方

`index.html` をブラウザで開くだけで動作します。外部ライブラリへの依存はありません。

GitHub Pagesで公開する場合は、リポジトリの Settings → Pages で `main` ブランチ / ルートを指定してください。

## スマホでアプリ化（PWA対応）

PWA（Progressive Web App）対応済みです。スマホのブラウザでページを開き、共有メニューから「ホーム画面に追加」すると、アプリのようにアイコンから起動できます。一度開いた後はオフラインでも遊べます。

- `manifest.json`：アプリ名・アイコン・テーマカラーの設定
- `sw.js`：Service Worker（オフラインキャッシュ）
- `icons/`：ホーム画面用アイコン（通常・maskable）
